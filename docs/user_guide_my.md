# Sit-Say Par အသုံးပြုနည်း

## Web UI
1. Browser တွင် `http://localhost:8000` သို့ သွားပါ။
2. သံသယဖြစ်ဖွယ် URL (သို့) စာသားနှင့် URL ရောနေသော စာတိုကို ထည့်ပါ။
3. "စစ်ဆေးမည်" နှိပ်ပါ။
4. အန္တရာယ်အဆင့်၊ အကြောင်းပြချက်နှင့် အကြံပြုချက်များ ပြသပါမည်။

## Telegram Bot
1. သင်၏ bot ကို Telegram တွင် ရှာပါ။
2. `/start` ဟုရိုက်ပါ။
3. URL သို့မဟုတ် စာသားကို ပို့ပါ။
4. Bot မှ စစ်ဆေးချက် ပြန်ပို့ပါမည်။

## API
- Swagger UI: `http://localhost:8000/docs`
- `POST /analyze` (JSON) ဖြင့် URL စစ်ဆေးနိုင်ပါသည်။
